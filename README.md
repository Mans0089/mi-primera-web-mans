## Cómo verla localmente

Solo necesitas abrir el archivo `index.html` en tu navegador, o servirlo con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

Desplegado en [Vercel](https://vercel.com/) como sitio estático, conectado directamente a este repositorio. Cada push a `main` genera un nuevo despliegue automático.
