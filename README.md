# Mi primera web en la nube

Página personal creada como práctica para la electiva de **Cloud Computing** (Noveno Semestre - Ingeniería de Sistemas). El objetivo del proyecto es construir un sitio web con HTML, CSS y JavaScript, y desplegarlo en la nube.

🔗 **Demo en vivo:** [mi-primera-web-mans.vercel.app](https://mi-primera-web-mans.vercel.app/)

## Características

- Diseño con efecto *glassmorphism* y fondo animado.
- 🌓 Modo claro / oscuro con preferencia guardada en el navegador.
- Animaciones de aparición de secciones al hacer scroll.
- Totalmente responsive.

## Estructura del proyecto

```
├── index.html          # Estructura y contenido de la página
├── css/
│   └── style.css        # Estilos, variables de tema y animaciones
├── js/
│   └── main.js           # Toggle de tema y animaciones al hacer scroll
├── assets/
│   └── favicon.svg       # Ícono del sitio
└── README.md
```

## Tecnologías

- HTML5
- CSS3 (variables, flexbox, animaciones)
- JavaScript (vanilla)

## Cómo verla localmente

Solo necesitas abrir el archivo `index.html` en tu navegador, o servirlo con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

Desplegado en [Vercel](https://vercel.com/) como sitio estático, conectado directamente a este repositorio.
